# HCC RNA-seq Classification

## Overview

This project investigates gene expression differences between hepatocellular carcinoma (HCC) tumor tissue and matched non-tumor liver tissue using RNA-seq data.

The goal is to explore whether gene expression profiles can be used to distinguish tumor samples from non-tumor samples.

## Scientific Question

**Can gene expression profiles distinguish hepatocellular carcinoma (HCC) tumor tissue from matched non-tumor liver tissue?**

## Dataset

The dataset used in this project is:

**RNA-seq of 50 Paired Hepatocellular Carcinoma Samples**

Source: [Refine.bio – SRP068976](https://www.refine.bio/experiments/SRP068976/rna-seq-of-50-paired-hepatocellular-carcinoma)

The dataset contains RNA-seq gene expression data from HCC tumor tissue and matched non-tumor liver tissue.

## Project Goals

* Explore and preprocess the RNA-seq gene expression data.
* Compare gene expression patterns between tumor and non-tumor samples.
* Identify genes or expression patterns that differ between the two groups.
* Investigate whether gene expression profiles can distinguish tumor from non-tumor tissue.
